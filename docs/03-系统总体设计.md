## 4. 关键设计点

- [ ] 统一响应封装 `{code,message,data}`
- [ ] 认证与授权分离（JWT 验身份 + AdminMiddleware 控角色）
- [ ] 操作审计可追溯（中间件与业务解耦）
- [ ] 真实虚拟化落地（非模拟数据）
- [ ] 状态实时同步（virsh 拉取回写 DB）
- [ ] 前端静态托管（单二进制 + web/dist）

## 5. 部署形态

- [ ] 单后端二进制 + 前端静态产物
- [ ] MySQL 8（本机或 Docker）
- [ ] 被纳管宿主机需 libvirt + KVM

## 6. 设计原则

- [ ] 一条主线（平台本身）
- [ ] 分时运行（VM 不常驻）
- [ ] 受限硬件硬预算
- [ ] 自研代码 = 论文工作量
- [ ] 每个技术点可回答「为什么选它」

# koko v4 资产菜单形态还原（据 /opt/koko/locale/zh 语言包词条实证）

从容器 /opt/koko/locale/zh/LC_MESSAGES/koko.mo 抽得的关键词条：
- 「输入资产[ID]直接登录」「搜索登录(如果唯一)」「/ + IP，主机名，备注」→ **搜索是第一交互**
- 「ID」「名称(资产数量)」「每页行数」「页码」「上一页」「下一页」「总页数」→ 表格 TUI + 页脚
- 「显示帮助」「返回」「提示」「刷新完成」「显示您有权限的资产」→ 快捷键条 + 权限口径文案

## koko v4 真实形态（还原）

```
 提示: 输入 ID 直接登录；输入 / + IP/主机名/备注 搜索；h 显示帮助
 ┌──────────────────────────────────────────────────────┐
 │ ID   名称                 地址          系统用户   连接 │
 │ 1    node1               10.0.0.2      root        是   │
 └──────────────────────────────────────────────────────┘
 页码: 1/1  总数: 1        上一页  下一页  每页行数: 100
```

特征（对照我们当前版的差距）：
1. **无欢迎语/无产品名横幅**——进来就是表格，提示压成一行
2. **搜索是一等交互**：`/关键词` 二级搜索；唯一命中直接登录
3. 列含「系统用户」「可连接」（连接前就知道账号与可达性）
4. 页脚是**快捷键/分页信息条**（非装饰框）；「上一页/下一页」而非单键翻页

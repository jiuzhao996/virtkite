## 七、易踩坑提醒（本会话实测）

- nginx 加新 vhost 会抢「字典序第一个」的隐式 default_server——多站点共存时给主站显式 `default_server`
- 未备案域名在腾讯云 80/443 被 SNI 间歇拦截（非标端口如 4321/8081 不受影响）
- `proxy_pass` 带尾斜杠 = 剥 location 前缀重写；配 `serve_from_sub_path` 的 Grafana 必须去尾斜杠透传
- VictoriaMetrics v1.150 已移除 `-httpAuthKey`，认证放 nginx 层做
- Ubuntu sshd 配置首现优先：`sshd_config.d/50-cloud-init.conf` 与主配置 120 行的 PasswordAuthentication 要同时清
- docker compose 改 environment 必须 `--force-recreate` 才生效
- Chrome 无头直截 SVG 不缩放（按原始尺寸画左上角），渲染 PNG 要用 HTML img 包装

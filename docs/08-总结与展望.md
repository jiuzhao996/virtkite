## 1. 工作总结

已完成功能回顾：认证与 RBAC 只读角色、宿主机管理、VM 生命周期、异步任务系统、会话跟踪与控制台三链路、镜像与模板、linked clone 与 cloud-init、硬件热管理（磁盘/网卡/核/内存）、存储池、网络、快照、审计、仪表盘、任务中心/会话管理/系统设置前端，以及创建向导与列表实时化。

核心成果：真实 KVM 建机、耗时操作异步化（202 + 轮询）、控制台会话可观测可收敛、增量克隆节磁盘、操作审计可追溯、单二进制轻量部署。

工程实践：Go + Vue3 + MySQL + libvirt 全栈；virt 封装层统一 libvirt 出口；任务队列与会话注册表两个后台子系统。

| 模块 | 工作量要点 |
|---|---|
| 异步任务子系统 | Task 模型、Manager（队列 + 4 worker）、5 executors、任务 REST 与任务中心页 |
| 会话跟踪 | Registry（内存 + DB）、三链路埋点、强制断开、VNC 过期清扫、会话管理页 |
| RBAC 只读角色 | OperatorMiddleware 规则矩阵、前后端读写边界 |
| linked clone | CloneVolumeFromVol / CloneVMFromSpec，VM 克隆与镜像建机共用 |
| cloud-init seed | GenerateSeedISO（纯 Go iso9660）、seed 目录、只读 cdrom 挂载 |
| 硬件管理 | DomainSpec 模型、磁盘/网卡热插拔、调核/调内存、VmDetail 分栏 |
| 列表实时化 | 列表 perf 聚合、详情 stats 轮询、系统设置轮询偏好 |

## 2. 后续工作

### 2.1 监控子系统（ exporter + 看板已落地）

- ✅ 已落地：后端内建 Prometheus exporter（`GET /metrics`，VM/宿主机/存储池/任务 4 类指标）+ 5 条告警规则 + Grafana 9 面板看板 + compose 一键监控栈。
- 待做：Alertmanager 告警网关（去重/分级/多通道）与 alertnotify 对接。
- 待做：服务发现闭环（平台建 VM → 自动被监控，目前靠 label 自动出现，缺 file_sd/target 元数据）。

### 2.2 混合云接入

- frp + WireGuard 打通家庭私有云与公有云。
- 域名规划（ops.jzops.fun / monitor.jzops.fun）。
- 双通道分工：frp 对外服务暴露、WireGuard 对内大流量。

### 2.3 功能扩展

- 存储池（Ceph RBD）。
- 腾讯云 CVM 纳管。
- P2 多宿主机连接池（当前 virt 连接按需获取，跨多宿主机并发与复用尚未优化）。

### 2.4 工程优化

- service/repository 分层。
- 参数校验、错误处理、日志优化。

> 说明：noVNC 网页控制台、快照/克隆、存储池、网络管理等早期展望项已在本轮实现，不再列为后续工作。

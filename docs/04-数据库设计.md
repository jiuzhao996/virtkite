## 1. 设计原则

- [ ] 5 张核心表覆盖 KVM 管理核心功能
- [ ] 软删除（DeletedAt）、外键约束 + 级联、适当冗余
- [ ] 建表与种子数据不依赖手工 SQL（AutoMigrate + initSeedData）

## 2. ER 图

- [ ] 实体关系图（mermaid）：users 1—N audit_logs、hosts 1—N vms、images 逻辑关联 vms

## 3. 表结构

### 3.1 users 表

- [ ] 字段：id、username、password_hash、role、is_active、real_name、phone、email、last_login、时间戳
- [ ] 种子账号：admin/password、user/123456

### 3.2 hosts 表

- [ ] 字段：name、libvirt_uri、ssh_ip、ssh_port、ssh_user、status、cpu/mem/disk、os_version、description

### 3.3 vms 表

- [ ] 字段：uuid、name、host_id(FK)、template、vcpu、memory_mb、disk_gb、ip、mac_address、status、os_type、description
- [ ] 状态枚举与 virsh 状态映射（running/shut off/paused/error）

### 3.4 images 表

- [ ] 字段：name、path、os_version、size_gb、format、is_template、description

### 3.5 audit_logs 表

- [ ] 字段：user_id(FK)、username(冗余)、action、object_type、object_id、detail、source_ip、status、created_at
- [ ] 操作类型枚举（login/create_vm/start_vm/stop_vm/restart_vm/delete_vm/create_host/...）

- [ ] AutoMigrate 自动建表

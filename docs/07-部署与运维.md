# 部署与运维

------

## 1. 部署形态

- [ ] 单后端二进制 + 前端静态产物
- [ ] 运行 vmops 的机器本身不必是 KVM 宿主机，但被纳管宿主机需能执行 virsh

## 2. 环境要求

- [ ] Go 1.21+ / Node.js 18+ / MySQL 8 / libvirt+qemu-kvm
- [ ] 网页控制台：novnc / websockify（`sudo apt install novnc websockify`）

## 3. 方式一：docker-compose 一键部署（推荐演示）

- [ ] 前端构建 → docker compose up -d --build
- [ ] 容器：vmops-mysql / vmops-app
- [ ] Dockerfile 适配前端说明

## 4. 方式二：源码编译部署

- [ ] 数据库准备（Docker 或 init-db.sql）
- [ ] 后端构建（go build）+ 启动
- [ ] 前端构建（npm run build）→ web/dist

## 5. 配置说明（.env）

- [ ] DB_HOST/PORT/USER/PASSWORD/NAME
- [ ] JWT_SECRET_KEY / JWT_EXPIRE_MINUTES
- [ ] SERVER_PORT / SERVER_MODE / CORS_ORIGINS
- [ ] LIBVIRT_URI / IMAGE_DIR

## 6. 运维与排错

- [ ] 常见问题表（数据库连接失败、libvirt 连接失败、权限拒绝、前端白屏、审计 username 为空）
- [ ] 网页控制台：需安装 `novnc` / `websockify`（`sudo apt install novnc websockify`）
- [ ] 一键启动：`./start.sh --service`（后端 + noVNC 无人值守）/ `./start.sh --stop` 停止
- [ ] libvirt 权限：运行用户需加入 `libvirt` 组（`sudo usermod -aG libvirt $USER`）

## 7. 备份与升级

- [ ] mysqldump 备份、qcow2 磁盘备份
- [ ] 升级流程（go build + npm run build 替换）

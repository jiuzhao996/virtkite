# 系统需求分析

> 对应论文章节：第三章 需求分析。
> 素材来源：旧《Go重构规划》功能模块筛选、旧《API设计》接口清单、代码 handler 实现。

[TOC]

------

## 1. 系统目标与定位

- [ ] 轻量级私有云管理平台（面向实验室/小型私有云）
- [ ] 核心：基于 KVM 对多宿主机 + 虚拟机统一管理
- [ ] 满足「可管、可控、可追溯」

## 2. 角色与权限

- [ ] admin（管理员）：全部操作权限
- [ ] viewer（普通用户）：只读
- [ ] 权限控制方式（JWT 角色 + AdminMiddleware）

## 3. 功能需求

### 3.1 认证与用户管理

- [ ] 登录（JWT 签发）、获取当前用户
- [ ] 用户 CRUD（admin）

### 3.2 宿主机管理

- [ ] 宿主机列表/添加/更新/删除
- [ ] 连通性测试、实时状态采集

### 3.3 虚拟机生命周期管理（核心）

- [ ] 列表 / 详情（实时同步 libvirt 状态）
- [ ] 创建（真实 KVM 建机：存储池建卷 StorageVolCreateXML + DomainDefineXML）
- [ ] 启动 / 停止 / 重启 / 删除

### 3.4 镜像管理

- [ ] 镜像上传（流式写入 + 安全校验）
- [ ] 列表 / 详情 / 删除

### 3.5 存储池管理（P1）

- [ ] 存储池列表（状态/容量/分配/路径）
- [ ] 卷管理：创建 / 克隆 / 删除
- [ ] 注册新池（路径安全校验）

### 3.6 网络管理（P1）

- [ ] 网络列表（网关/IP段/转发方式/DHCP）
- [ ] 网络启停 / 删除
- [ ] 网络 XML 查看 / 编辑
- [ ] 创建网络（NAT+DHCP / macvtap / 从 XML）

### 3.7 网页控制台（P1）

- [ ] noVNC 控制台（websockify + token 动态接口，参考 vmdashboard）
- [ ] 仅运行中 VM 可连、token 一次有效

### 3.8 快照管理（P1）

- [ ] 快照创建 / 删除 / 回滚 / 列表
- [ ] 级联删除（参考 KvmDash）

### 3.9 VM 详情增强（P1）

- [ ] 磁盘增删、光驱挂载、网卡增删
- [ ] 按 OS 平台自动选设备型号
- [ ] 原始 XML 查看 / 校验后编辑（可回滚）

### 3.10 审计日志

- [ ] 中间件自动记录操作
- [ ] 列表查询（多条件筛选 + 分页）/ 详情 / 操作类型分布

### 3.11 仪表盘

- [ ] 平台总览统计
- [ ] 虚拟机状态分布
- [ ] 内存真实统计（libvirt memory_stats，参考 KvmDash）

## 4. 非功能需求

- [ ] 性能：接口响应、KVM 操作耗时
- [ ] 安全：JWT 鉴权、bcrypt、目录穿越防护、输入校验
- [ ] 易用性：Web 管理界面、六页面覆盖
- [ ] 可维护性：分层结构、统一响应封装
- [ ] 可部署性：单二进制 + 前端静态托管

## 5. 测试结果与分析

- [ ] 接口测试用例表（编号/输入/预期/实际/结论）。
- [x] 审计数据分布图表素材（DB 现有 380+ 条，覆盖 9 种操作）。
- [x] 问题与修复记录：
  - 存储池卷名含扩展名被拒 → 放开卷名校验（允许 `.`）。
  - 删除运行中 VM 域残留 → UndefineDomain 先 Destroy 再 UndefineFlags。
  - 有快照的 VM 删除失败 → UndefineFlags 带 SNAPSHOTS_METADATA。
  - ConnectListAllDomains NeedResults=0 返回空 → 传 1。
  - 同步 Stop 15s 撞 axios 超时 → 转异步 `stop_vm` 任务 + 前端轮询。
  - VNC 会话幽灵残留 → token 解析刷新 + 60 分钟过期清扫收敛。

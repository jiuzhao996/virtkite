## 4. 虚拟机生命周期模块（核心）

- [ ] 列表/详情（go-libvirt 状态同步：ListAllDomains + DomainGetState）
- [ ] 创建：生成 UUID/MAC → DB 写入 → **存储池建卷（StorageVolCreateXML，qcow2）** → DomainDefineXML → 失败回滚
- [ ] 启停/重启/删除（DomainCreate / Shutdown+Destroy / Reboot / Undefine+存储卷删除）
- [ ] 建盘走 libvirt 存储池/卷 API（对应 virsh vol-create-as），支持多存储池选择（默认 vmops）
- [ ] 停止策略：优雅关机 + 轮询（15s）超时强制断电
- [ ] 删除策略：运行中先 Destroy 再 Undefine，再删存储卷
- [ ] domain XML 模板、名称校验、随机 MAC/UUID
- [ ] 存量 VM 导入/纳管：扫描 libvirt 全部域（ListDomainsWithDetail，解析 XML 取 vCPU/内存/MAC/磁盘路径），与 DB UUID 比对筛出未纳管域，勾选导入只写 DB、不改 libvirt；磁盘归属按存储池路径前缀推断
- [ ] 关键代码要点：handler/vm.go、service/virt/domain.go、service/virt/storage.go、service/virt/import.go

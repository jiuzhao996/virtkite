# P1 · 网络通信可视化（流量图）

## 目标
宿主机/libvirt/Docker 三域网络间实时通信一眼看清：谁在跟谁通信、流量怎么走。

## 数据面（后端，全新 handler/network_flow.go）
- GET /api/network/flows（operator+，轮询 3s）：
  - 网络清单：libvirt 网络（name/网段/网桥）+ Docker 网络（inspect 网段，复用 NetworkDetails）+ 宿主机 + 外部（兜底类）
  - 连接边：ss -tn 采样（无需 root）→ 每条连接 local/peer IP 按网段归类 → 聚合 {from_net, to_net, conns, 样例进程}
  - 实时速率：/proc/net/dev 对 virbr0/docker0/br-*/eno1 等做两次采样差分（间隔 1s）→ 每接口 rx/tx bps
  - IP 归网：CIDR contains 匹配；未命中任何网段 → "外部"
- 复用：DockerGate 不需要（非 docker 依赖）；libvirt ListNetworks 现成

## 视觉面（前端，拓扑页扩展）
- 拓扑 tab 加「流量」开关（或独立第四 tab）：网络节点图 + 连线用 ECharts graph line effect（show:true, symbolSize 按连接数, trailLength 流动感）
- 每网节点 tooltip：实时 rx/tx 速率 + 连接数；边 tooltip：连接数 + 样例进程名
- viewer 可见（只读安全）

## 验收
- 本机能看到 vmops↔mysql(172.18)↔宿主 的边；速率随实际传输变化；外部 443 流量归"外部"节点

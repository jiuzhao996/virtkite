# P3 · 版本检测与更新（CC-Switch 式）

## 目标
平台内看到已部署组件的版本与可更新提示。

## 数据面
- 容器侧：docker inspect 镜像 tag vs registry 最新（走国内代理 registry：dockerhub via 镜像加速 / 厂商 registry 直连）；失败静默降级"未知"
- VM 应用侧：apps catalog 每项加 version_detect（detect 脚本输出版本）+ known_latest（目录维护）；比对出"可更新"
- 展示：应用商店/栈卡片角标"有新版本"；详情页当前 vs 最新

## 排期理由
依赖外网与各上游 API 形态，放 P2 之后；纯增量功能，随时可做可停。

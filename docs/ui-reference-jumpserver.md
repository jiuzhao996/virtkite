# JumpServer v4 Web 布局借鉴要点（实地侦察记录）

> 侦察对象：本地容器 `vmops-jms-ref`（jumpserver/jms_all:v4.10.19，GPL-3.0）。
> **红线惯例不变：只学布局行为，不引入其代码**；本文截图均为本地容器实拍，仅作设计参照。
> 侦察日期：2026-09-26。截图在本目录 `img/jms-*.png`。

## 整体框架

- 三段式：深绿顶栏（约 48px）→ 白色窄左导航（约 200px）→ 浅灰内容区。
- 顶栏极简：Logo 居左；右侧全局搜索（Ctrl+K 角标）+ 铃铛/设置/语言/头像，无面包屑。
- 左导航为「灰色小字分组标题 + 线性图标条目」两级；选中项 = 浅绿底色块 + 绿字。
- 页头模式：`← 返回 + 标题 (+ 问号说明)`，子场景用页头下横向 Tab（如命令过滤/命令组）；无传统面包屑。
- 路由为 hash SPA，**列表页树节点选中状态写进 URL 查询参数**（`?node_id=...`），刷新可还原——值得学。

## 资产列表页（最值得借鉴，见 img/jms-60-assets-with-data.png）

- **左树右表约 1:2.3**，中间可拖拽折叠；树面板顶部「资产树/类型树」双 Tab + 搜索/刷新小图标。
- 表格工具行：左「创建∨」主分裂按钮 +「更多操作∨」；右侧图标组 + 带 `/` 快捷键角标的搜索框。
- 表格列：勾选 | 名称(青绿链接)↕ | 地址↕ | 账号 | 平台(tag+图标) | 上次登录 | **操作列固定右侧，仅「连接」+「...」两个小钮**——极度克制。
- 底部信息条：左「共 N 条」，右「页大小 + 分页器」，当前页实心品牌色块。
- 用户列表页变体：**「快速过滤」文字链组**（竖线分隔的纯文字链：无效|已禁用|过期…）替代一排下拉——高频筛选快捷化。
- 授权类页面页头下加**可关闭浅蓝说明横幅**，一句话解释规则用途。

## 详情页（核心亮点：全屏抽屉，见 img/jms-100-asset-detail.png）

- 点名称链接 → 右侧滑出**近全屏抽屉**（父页面透出约 1/5 并蒙灰），头为「资产: xxx」+ 关闭钮。
- 抽屉内第一层横向 Tab：把关联数据全收进同层（基本设置|账号|授权用户|会话记录|命令记录|活动），**不跳页**。
- Tab 内容「左主右辅」两栏：左 2/3 白卡**无边框两列表格**（标签左对齐、值右对齐、浅灰横线分行）；右 1/3 竖排小卡「快速更新」（每行一个高频操作按钮）+ 节点/标签。
- 「左侧读信息、右侧做高频操作」的分区是这页最舒服之处。

## 配色质感

- 主色青绿系（与我们 #2a9da5 气质接近）；白卡 + 浅灰底区分层次，**卡内用 1px 浅灰线而非新卡**；行 hover 才高亮、无斑马纹；圆角极小（2-4px）；整体轻拟物扁平，不靠阴影堆质感。

## 对 vmops 的取舍（直接搬 vs 不搬）

**直接搬**：左面板+右表格双栏骨架、详情大抽屉+Tab+左信息右操作卡、快速过滤文字链、`←+标题`页头、操作列瘦身（1 主钮+...）、授权页说明横幅、分页信息条布局、树/筛选状态进 URL。
**不搬**：深色实心顶栏与整排全局图标、六域完整分组导航（收敛为我们现有 4 组）、资产树/类型树双 Tab 与网域概念、平台图标装饰列、插画登录页。

## 1. 选题背景与意义

## 3.1 系统边界与范围判据（防跑题锚点）

> 论文题目关键词是**「私有云管理平台」**，而非「虚拟机管理工具」。所有功能取舍以是否支撑以下三个贡献点为判据：

| 贡献点 | 含义 | 支撑功能 |
|---|---|---|
| ① 轻量私有云 | 单二进制、低资源、**多宿主机纳管** | 宿主机管理、资源统一抽象、单二进制部署 |
| ② 真实 KVM 落地 | 非模拟，生命周期自动化 | VM 建/启停/删、镜像模板、存储池、网络 |
| ③ 操作审计可追溯 | 谁/何时/对什么/结果 | 审计中间件 + 查询 + 分布统计、角色权限 |

**与单机管理工具（virt-manager/Cockpit）的差异**：它们重在「单机全功能手工操作」；本平台重在「多机纳管 + API 标准化 + 审计留痕」。XML 直接编辑属工具思维，本平台以「结构化表单 + 模板」为主，原始 XML 编辑作为高级能力补充——这本身就是可写的设计点，不是减分项。

## 3.2 功能范围（激进版，对齐 virt-manager 全功能）

| 模块 | 档位 | 状态 | 说明 |
|---|---|---|---|
| 认证 + 角色权限 | P0 | ✅ 已有 | JWT + admin/viewer |
| 宿主机纳管 + 状态 | P0 | ✅ 已有 | 多机纳管、连通性、实时状态 |
| VM 生命周期 | P0 | ✅ 已有 | 建/启停/重启/删（真实 KVM） |
| 镜像模板 | P0 | ✅ 已有 | 上传/列表/删除 |
| 审计日志 | P0 | ✅ 已有 | 写入 + 查询 + 分布 |
| 仪表盘 | P0 | ✅ 已有 | 总览 + 状态分布 |
| **网页控制台（noVNC）** | P1 | 🔧 待补 | 参考 vmdashboard token 机制 |
| **存储池管理** | P1 | 🔧 待补 | 池列表/卷管理/注册（参考 vmdashboard） |
| **网络管理** | P1 | 🔧 待补 | 网络列表/启停/XML（NAT/macvtap） |
| **VM 详情增强（磁盘/网卡/硬件）** | P1 | 🔧 待补 | 参考 vmdashboard domain-single |
| **快照管理** | P1 | 🔧 待补 | 创建/删除/回滚，级联删除（参考 KvmDash） |
| **XML 编辑（高级）** | P1 | 🔧 待补 | dumpxml + 校验后 define（可回滚） |
| 硬件热添加（CPU/内存） | P2 | 📌 展望 | 非核心，论文「展望」章节 |
| 监控集成（Prometheus） | P2 | 📌 展望 | 详见 docs/08 |

> 实现顺序建议：P1 内先做「存储池 → 网络 → 网页控制台 → 快照 → VM 详情增强 → XML 编辑」。

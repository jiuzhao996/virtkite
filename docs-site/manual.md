# 使用手册

按左侧菜单逐节说明。每节回答三件事：这个页面是干嘛的、日常怎么用、有哪些容易忽略的细节。

## 虚拟机（最常用页面）

### 创建：三种方式怎么选

| 方式 | 适用场景 | 特点 |
|---|---|---|
| **云镜像**（推荐） | 批量做实验机 | 几十秒出机，cloud-init 自动注入账号 |
| ISO 光盘 | 装特定系统/演示装机过程 | 走传统安装流程，慢但直观 |
| 克隆 | 基于某台配置好的机器复制 | 增量盘不复制数据，初始近零占用 |

### 日常操作

- **开关机/重启**：列表卡片或详情页右上角。关机是「优雅关机」（等于按电源键），卡死时用详情页的强制停止
- **控制台**：VNC（图形界面）/ SSH（命令行）/ 串口（救砖）。机器网络挂了用串口
- **硬件热调整**：详情页磁盘/网卡分区，运行中可直接加盘、加网卡
- **快照**：做危险操作前拍一个；回滚 30 秒恢复
- **文件管理**：机器开着走 SSH/SFTP；关了走离线挂载（只读，防锁盘）

### 小贴士

- 列表卡片上的 **IP 点击即复制**
- 删除是**软删除**：先进回收站，误删可恢复
- 增量克隆的机器**删除源机也不受影响**（删除时有卷守卫，依赖盘自动保留）

## 镜像管理

- **三个 tab**：云镜像（系统模板盘）/ 模板盘 / ISO
- **镜像市场**：内置官方云镜像清单一键下载，完成自动入库
- **上传镜像**：支持本地 ISO 上传（大文件走异步任务，可关页面）

## Docker 管理（基础设施组）

管理宿主机上 Docker：容器 / 镜像 / 网络 / 卷 / 编排五个 tab。日常三件事：

1. **创建容器**：抽屉里填镜像名和端口映射，等于 `docker run` 的图形版
2. **查日志**：容器行点「日志」，支持实时跟随、下载、复制
3. **compose 项目**：`docker compose up/down` 图形化

## 应用商店

20 个内置应用（nginx / mysql / redis / gitea / jenkins…）。选择目标虚拟机 → 填动态表单（应用包声明式定义）→ 一键安装 → 任务轮询进度。安装脚本经 SSH 在虚拟机内幂等执行，重复安装自动跳过。

## 资产申请（学生入口）

1. 选一台运行中的虚拟机 + 写理由（至少 5 个字）+ 选时长
2. 提交后等教师审批，状态在「我的申请」实时可查
3. 批准后虚拟机**立刻出现在你的虚拟机列表**，到期自动收回

详见 [4A 教学闭环](/4a)。

## 监控中心

- **实时告警**：9 条内置规则（VM 全挂 / 主机 CPU 过热 / 存储池将满 / 任务堆积…）
- **Grafana 看板**：宿主机 5 面板 + 虚拟机 6 面板（iframe 嵌入）
- **历史曲线**：Prometheus 当历史库，刷新不清零
- **告警推送**：设置页填飞书/钉钉机器人地址，告警恢复也会通知（不重复轰炸）

## 审计中心

两个 tab：**操作日志**（谁在什么时候动了什么，含跳板拦截的危险命令）+ **会话列表**（控制台会话，可强制断开）。

## 用户管理

- 三级角色：**admin**（全部）/ **operator**（操作虚拟机）/ **viewer**（只读 + VNC 观看）
- **用户组 tab**：建组 → 拉成员 → 在虚拟机详情里按组授权，一个班一次搞定
- 密码策略与登录安全入口在系统设置页

## 系统设置（管理员）

| 卡片 | 作用 |
|---|---|
| 运行参数 | 默认存储池 / VNC token 有效期 / **跳板命令黑名单** |
| AI 设置 | 填 OpenAI 兼容接口后，顶栏出现 AI 运维助手（Key 只存服务端） |
| 安全设置 | 登录安全入口（防扫描）+ 密码最小长度 |
| SSH 主机密钥 | TOFU 指纹管理：虚拟机重建后删旧记录重连 |
| 告警通知 | 飞书/钉钉 webhook |
| 系统公告 | 登录页与仪表盘顶部展示 |

# 4A 教学闭环

对标堡垒机（JumpServer）的 4A 体系——**认证（Authentication）、账号（Account）、授权（Authorization）、审计（Audit）**——但为教学场景重新设计：教师批量管学生、学生自助申请、危险操作有护栏。本章四个功能全部是自研实现。

## 场景先想象一下

> 教师：「下周网络课，每人一台 Rocky 虚拟机练 systemctl，周五回收。」
> 学生 A：「老师我机器不够用，能再要一台吗？」
> 平台把这两句话变成了三条点击。

## 1. 用户组授权——给「一个班」批量开机

传统做法：30 个学生 × 逐个授权 = 30 次重复操作。
本平台做法：

1. **用户管理 → 用户组 tab → 新建用户组**（如「网络 2401 班」）
2. **管理成员**：多选框勾入全班学生（保存即全量替换）
3. 进任意虚拟机详情 → **授权管理 → 按用户组** → 选组、设到期时间 → 授权

效果：组内所有成员**立刻**能在自己的虚拟机列表看到这台机器；到期或移出组，**立刻**不可见。没有缓存、没有延迟。

## 2. 授权申请 + 审批——学生的自助通道

学生看不到未授权的机器（连「它存在」都不暴露），那怎么知道有什么可申请？「资产申请」页给了答案：

**学生侧**：

- 页面列出全部运行中虚拟机的**花名册**（只有名称和状态，没有 IP 等敏感信息）
- 选机器 → 写理由（「网络 2401 班实验作业…」）→ 选时长（2h ~ 168h）→ 提交
- 「我的申请」实时看进度

**教师侧**（同一页面，admin 登录自动切换为审批台）：

- 待审批队列显示申请人 / 虚拟机 / 理由 / 时长
- **批准**：可修改授权时长 → 系统自动写入限时授权
- **驳回**：填原因，学生端可见

安全细节：同机重复申请自动去重；已有授权的机器不允许申请；审批只延长不缩短既有授权。

## 3. SSH 跳板——任意终端直连资产

不想开浏览器？任何终端工具（Xshell / iTerm / Windows cmd）：

```bash
ssh stu@服务器IP -p 2222
# 输入平台密码后出现交互式菜单：
# ┌─────────────────────────────────────────────┐
# │  鸢航 VirtKite 资产菜单（仅显示你有权连接的虚拟机）
# ├─────────────────────────────────────────────┤
#   1. node1 (10.0.0.2)
# ├─────────────────────────────────────────────┤
#   第 1/1 页 ｜ 数字选择 ｜ j 下一页 ｜ q 断开退出
# └─────────────────────────────────────────────┘
```

按数字直达虚拟机 shell；`exit` 回菜单；`q` 断开。

**为什么它比直接发虚拟机密码安全**：

| 攻击面 | 直接发密码 | 跳板模式 |
|---|---|---|
| 连接目标 | 学生自己输 IP（想连哪连哪） | 服务端从授权库决定，**只能选单** |
| 文件外传 | scp/sftp 随意 | sftp/scp/端口转发**全部拒绝** |
| 爆破 | 撞库虚拟机 | 平台密码 + per-IP 限流（1 分钟 5 次锁定） |
| 密码扩散 | 一传十十传百 | 学生不知道虚拟机密码（凭据托管加密） |

## 4. 命令黑名单——看得见的安全护栏

学生连上机器后敲 `rm -rf /` 会怎样？

```
root@node1:~# rm -rf /tmp/whatever
✗ 危险命令已被安全策略拦截并审计：rm -rf /tmp/whatever
```

- **命令没有执行**（整行不送达目标机，残留输入自动清除）
- **审计中心当场出现记录**（操作日志 tab，谁、何时、敲了什么）
- 黑名单可在 **系统设置 → 跳板命令黑名单** 自定义（默认含 rm -rf / mkfs / dd if= 等）
- 全屏程序（vim/htop）不受影响——只有「整行命令」才参与判定

## 5. 审计——两条通道一个账本

Web 终端、SSH 跳板的每一次会话都进 **审计中心**：

- 会话列表：谁、从哪个 IP、连了哪台机器、多久、什么类型（vnc/ssh/serial/jump）
- 操作日志：平台内的写操作 + 跳板拦截的危险命令（`jumpd.cmd_blocked`）

「任意终端连资产」和「Web 全功能」共享同一套账号与授权——这就是 4A 闭环。

## 快速体验路径（教师视角 5 分钟）

1. 用户管理 → 建组「demo 班」→ 拉入 stu
2. VM 详情 → 授权管理 → 按用户组授权 demo 班（到期设 2 小时后）
3. 终端 `ssh stu@本机 -p 2222` → 菜单里出现这台机器 → 连上
4. 敲 `rm -rf /tmp/x` → 看拦截红字 → 审计中心看记录
5. 另一个学生账号登录 → 看不到这台机器（未授权）→ 资产申请页提交申请
6. admin 审批队列批准 → 学生列表当场多出机器
